# Privacy Policy — Email Responder

This is a personal automation tool built by Hamais Ahmed for his own use.

## What it does
This application accesses the Gmail account of its owner only, to:
- Read unread emails
- Generate draft replies using the Groq API
- Save those drafts back into the same Gmail account for manual review

## Data handling
- No data is shared with, sold to, or accessed by any third party
- Email content is sent only to the Groq API solely to generate draft reply text
- No data is stored outside the owner's local machine and their own Gmail account
- Nothing is ever sent automatically — all drafts require manual review and sending by the account owner

## Scope
This tool is for personal use only and is not intended for use by the general public.
